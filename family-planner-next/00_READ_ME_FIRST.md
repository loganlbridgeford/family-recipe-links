# Read this first

This folder is a plan, not a finished rewrite.

Use it in this order:

1. You read `01_MARKET_AND_POSITION.md` (5–10 min).
2. You read `02_PRODUCT_DECISIONS.md` so you agree with the four feature calls.
3. You do the work in `03_CURSOR_STEPS.md` one numbered step at a time.
4. Keep `04_INTEGRATIONS_TRUTH.md` handy when anyone asks “can it talk to Reminders?”

Do **not** paste this whole folder into Cursor at once.
Open `03_CURSOR_STEPS.md` and paste **one step** into Composer.
Wait until that step works on a preview URL before starting the next step.

If a step fails, stop. Do not let Cursor “finish the rest.”
