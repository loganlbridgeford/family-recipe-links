Family Planner privacy

Family Planner is a household meal and grocery app. This page covers the website and the iPhone app.

No login

There is no Apple ID, Google, or email account inside the app. You join a kitchen with a family invite code (or start a new kitchen). That code is stored on the phone so you do not re-enter it every time.

What we store

  • Recipes you add (name, ingredients, steps, optional photos, source link).
  • This week’s meals, grocery check-offs, and extra list items.
  • Household member first names you type when you start a kitchen.

That data lives in our database so both phones share one week. Photos go to a file bucket used only for this app. We do not sell data, run ads, or use analytics / crash / advertising SDKs.

Camera and photos

If you add a recipe card photo, the app asks for the camera or photo library. Pictures are stored so the household can see the card. We do not scan your camera roll in the background.

Recipe websites

If you paste a recipe URL, our server fetches that page once to copy ingredients and steps into your kitchen. We do not crawl the web for you.

Leaving

Deleting the app removes the invite code from that phone. The household’s recipes stay until a family owner asks us to delete the kitchen.
